## Honest scope

These assets assume:
- The product is in pilot stage (not GA, not enterprise)
- Pricing is conversation-first (no public pricing page)
- The Knot / WeddingWire integrations are operator-drafted (no public APIs)
- Instagram DM sending is awaiting Meta App Review (operator-drafted in the interim)
- No SOC 2 / GDPR certification claims
- No guaranteed-revenue claims anywhere

**If you need to update these constraints** (e.g. Meta App Review approves and you can pitch live IG sending), update `docs/GTM-POSITIONING.md` first, then ripple changes through these assets.
